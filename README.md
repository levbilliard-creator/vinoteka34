# VINOTEKA34

Статическая витрина существующего сайта https://vinoteka34.ru/.

## Рабочие файлы

- `index.html` и `app.js`: главная, видео и режим уменьшенного движения.
- `catalog.html` и `catalog.js`: категории, поиск и порционная загрузка.
- `product.html` и `product.js`: карточка и похожие товары.
- `product-data.js`: общие правила отображения, фото, цен и URL.
- `styles.css`: единые стили и адаптивные сетки.
- `data/products.json`: отображаемые товары, стабильные ID и цены.
- `data/inventory.json`: отдельная исходная выгрузка, не подключена к витрине.
- `data/images.json`: индекс фотографий; витрина больше не угадывает фото по нему.
- `assets/wines/`: исходные фотографии; `assets/product-placeholder.svg`: заглушка.
- `catalog/index.html` и `product/index.html`: переходы со старых адресов с сохранением параметров.

## Правила работы с данными

Не менять ID при сортировке и очистке. Не связывать учетную выгрузку и товары по номеру строки. Не заменять цены и остатки без проверенного соответствия учетных кодов. Исходные выгрузки сохранять отдельно.

`image` — явное имя файла в `assets/wines/`. При отсутствии фото использовать заглушку; не подбирать другого производителя по похожим словам. Русское имя и оригинальное название показываются отдельно. Цвет и сахар — отдельные характеристики. Существующие 48 поврежденных названий и подозрительные привязки фото требуют отдельной сверки источников.

## Публикация и откат

Установлена побайтовая идентичность исходной main-версии и опубликованных index.html, catalog.html, catalog.js, product.html, product.js, styles.css и data/products.json. В переписке от 26.04.2026 указан Яндекс Облако Object Storage, новый бакет vinoteka34.ru, веб-хостинг с index.html. Доступ к бакету из текущей сессии пока не подтвержден; автоматическая публикация из GitHub не установлена.

Не считать изменение GitHub публикацией на vinoteka34.ru. Не переносить домен и не создавать новый хостинг для обновления.

Комплект обновления содержит UPDATE с файлами для действующего корня сайта и ROLLBACK с предыдущими версиями заменяемых файлов. Сначала загрузить новый product-data.js, app.js, catalog.js, product.js и SVG, затем CSS и HTML. Существующие data и assets/wines не заменять. Новые JS-ссылки имеют версию 20261114-1. После загрузки проверить домен и при наличии CDN очистить кэш HTML. Для отката заменить файлы из ROLLBACK; новые неиспользуемые файлы можно оставить, они не вызываются старым HTML.
